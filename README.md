## 這是什麼、解決什麼問題

總部小教室課件（Keynote）對專員來說「太專業、不好改」，大家真正要的是**打開就能講的成品**，不是一個要學操作的工具。
這支生成器把「選主題 → 換照片文字 → 匯出」壓到最少步驟，講師好上手、顧客看得親切。

## 兩支平行版本（放在同一資料夾）

| 檔案 | 版本 | 結構 | 什麼時候用 |
|---|---|---|---|

## 怎麼用（simple.html）

1. **選分類**（iPhone／iPad／Mac／Watch／App‧服務／AI／其他）→ **選主題**（支援新手推薦 ⭐ 星等篩選）→ 按「帶入」，整份草稿自動填好
2. 換成自己的：改文字、上傳「一起動手」示範照片、填講師名（可留空，純本機儲存）
3. **即時備忘錄與課前速覽**：
   - 簡報預覽區下方**即時連動顯示該頁講師備忘錄**（包含口語轉場、互動提問、講師動作引導、避坑提示）
   - 提供「課前 3 分鐘速覽卡」（時間配速、設備檢查、現場常見救援 3 招）
4. 上台與匯出方式：
   - **全螢幕播放**（←→ 換頁、按 N 顯示備課重點、Esc 離開）
   - **下載簡報** → 產出 `.pptx`，**Keynote / PowerPoint 可開可編輯**，備課重點會自動寫入「演講者備忘稿」
   - **備課單** → 可下載成獨立 HTML，直接 Cmd+P 列印或存成 PDF

## 核心避坑與踩坑排除紀錄（已納入系統記憶，不再犯錯）

### 1. Safari 原生 `<select>` 彈出選單卡死問題
- **踩坑現象**：在 Mac 或 iOS Safari 瀏覽器中，原生 `<select>` 容易受外層 flex、sticky 或自訂樣式影響，點擊展開後無法順暢收合。
- **解法與規範**：全介面全面升級為**自訂下拉選單（`.custom-dropdown`）**與**快捷分類藥丸按鈕**。支援「點擊選項即關閉」、「點擊外部任意處即關閉」、「按 ESC 鍵即關閉」三大安全收合機制，徹底根除 Safari 卡死問題。

### 2. PPTX 匯出時使用者反饋「看不到講師備忘錄」
- **踩坑現象**：PptxGenJS 寫入的 `slide.addNotes()` 在 Keynote 與 PowerPoint 中預設為隱藏（未開啟備忘錄視窗），導致使用者誤以為備忘錄未匯出。
- **解法與規範**：
  1. 匯出邏輯確保將每頁備忘錄、提問句、動作提示與避坑技巧完整寫入 Notes。
  2. 在使用者點擊「下載 PPTX」完成後，**自動彈出友善操作指引**（Keynote: 顯示方式 → 顯示簡報者備忘錄 ⌥⌘P；PowerPoint: 檢視 → 備忘稿），徹底弭平軟體認知落差。

### 3. 最高安全與隱私防護鐵則
- **零個資與敏感資訊**：內部心得回饋、主管檢討、門市營運業績數據，**嚴格禁止寫入程式碼或 Git Commit 紀錄**。
- **純本地端儲存機制**：使用者自訂之門市名稱、講師姓名與課程草稿，**100% 僅儲存於使用者瀏覽器本地端（`localStorage`）**，完全純前端運算，絕不發送外部網路請求。
- **零金鑰外洩風險**：本專案採用純靜態 HTML/JS 架構，不依賴任何外部後端 API Key 或 Token。
- **儲存庫隱私控制**：如需對外完全隱蔽，隨時可切換為 Private 私有儲存庫或僅保留 iCloud 本地端檔案。

### 4. 繁中文案與排版硬約束
- **100% 台灣在地正體中文**：零中國大陸用語（如性價比轉 CP 值、聯動轉連動、APP 轉 App 等）。
- **嚴格禁止破折號**：禁止使用破折號 `—`（`U+2014`）與 `–`（`U+2013`），一律改用連字號 `-`、全形直線 `｜` 或中圓點 `·`。
- **門市守則紅線**：全通路門市通用：支援各門市自由套用與彈性自訂店名；配件推薦依各門市陳列現貨彈性推薦，嚴守無現場拆機維修與無換電池之官方紅線。

### 5. 後續不上傳至 GitHub 鐵律與台灣官網唯一校正準則
- **不上傳至 GitHub 鐵律**：後續所有修正、更新與新產出之內容，**嚴格禁止上傳至 GitHub，絕對不執行 git push**！所有正式檔案 100% 只保存在本地端 iCloud Drive 專屬資料夾中，杜絕遠端外洩可能。
- **台灣官網唯一校正準則**：所有課綱之功能名稱、規格參數、系統版本，一律以「台灣蘋果官方網站（apple.com/tw）」釋出之最新正體中文資訊為唯一校正準則（如：原況照片 (Live Photo)、隔空播放 (AirPlay)、同播共享 (SharePlay)、統一記憶體等）。
- **全流程安全隱私保障**：修改與操作過程完全在本地端完成，零敏感數據外流。
